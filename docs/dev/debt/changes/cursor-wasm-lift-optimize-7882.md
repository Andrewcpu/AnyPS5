# relinker

## add Functional

- The [WebAssembly lift optimizer](../../../core/relinker/wasm/aot/src/Lift.cpp) keeps each guest GPR in an SSA value for one recovered block and spills it before a guest memory access and at a block edge. A 32-bit write stores the zero-extended value. Flag writes that do not reach a later conditional branch, PUSHFQ, live INC or DEC, or the halt that publishes RFLAGS are omitted. INC and DEC preserve CF, so a write that reaches a live one is kept. A fault between an omitted update and the next writer leaves the earlier flags in the state page. Direct jumps, branches, fallthroughs and calls to recovered blocks branch there. A return switches on the popped address to a recovered call fallthrough and uses the RIP dispatch switch otherwise. An import call continues at its fallthrough when the wrapper's return address matches. The step limit counts entries of recovered blocks and import dispatch labels. Closes when: an omitted flag update matches a native fault frame.
