# relinker

## add Functional

- The [WebAssembly lift optimizer](../../../core/relinker/wasm/aot/src/Lift.cpp) keeps each guest GPR in an SSA value inside one recovered block and spills it to the CPU-state page before a guest memory access and at a block edge. A 32-bit write replaces that value with the zero-extended result. Flag writes that do not reach a later conditional branch, PUSHFQ, INC, DEC, or the halt that publishes RFLAGS are omitted. INC and DEC keep the carry flag, so a write that reaches one of them is kept when that INC or DEC's flags are read. A faulting access between an omitted update and the next writer leaves the earlier flags in the state page. Direct jumps, conditional branches, fallthroughs and calls to recovered blocks branch to those blocks. A return switches on the popped address to the fallthrough of a recovered call and uses the RIP dispatch switch for every other address. A RIP-relative import call continues at its fallthrough when the wrapper's return address matches, and dispatches otherwise. The one million step limit counts entries of recovered blocks and of import dispatch labels; a direct edge does not add another count. Closes when: an omitted flag update matches a native fault frame.
