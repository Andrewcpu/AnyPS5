# relinker

## add Functional

- The [WebAssembly import wrappers](../../../core/relinker/wasm/aot/src/Imports.cpp) bind an undefined `R_X86_64_GLOB_DAT`, `R_X86_64_JUMP_SLOT` or absolute relocation by NID. A qualified `name#library#id` uses the text before the first `#` as the NID and checks the module id the way the guest image reader does. An unscoped name that is already a wrapped NID binds as written. An unscoped symbol name is hashed with `Nid::ComputeNid` only when a `DT_NEEDED` entry ends in `.sprx`, `.suprx` or `.debug_prx`, as the Linux patcher does. The wrapped set is `memcpy`, `memset`, `strlen` and `sceKernelGetProcessTime`. Any other undefined symbol throws. Each wrapper reads the System V argument registers, calls the replacement, and writes `RAX` and the return address back into the CPU state. `memcpy` and `memset` copy forward one byte at a time and fault when a range leaves the guest window; overlap is not measured against the console. `strlen` faults when the window ends before a NUL. `sceKernelGetProcessTime` returns microseconds from the host import `env.anyps5_host_monotonic_us` minus the sample taken at the start of `anyps5_run`. A weak undefined symbol still resolves to 0. Closes when: the remaining libkernel and libc imports a guest can reach are wrapped.
