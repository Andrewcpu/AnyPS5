# relinker

## add Functional

- The [WebAssembly lifter](../../../core/relinker/wasm/aot/src/Decode.cpp) does not vendor Remill. Remill's build find_packages a pinned LLVM and also glog, gflags and XED, so it is not a source-only 3rdparty submodule this tree can build with the relinker. Unimplemented opcodes throw. This pass lifts MOV, 8-bit MOV of the low byte registers, MOVSXD, CDQE, CWDE, LEA, ADD, SUB, CMP, AND, OR, XOR, TEST including an 8-bit `test al`, SHL, SHR and SAR by an immediate or CL at 32 and 64 bits, two- and three-operand IMUL, unsigned DIV, INC, DEC, SETCC, PUSH, PUSHFQ, POP, JMP, Jcc, CALL, RET, MOVD, MOVQ, PXOR and NOP; HLT, UD2, INT3 and SYSCALL halt. AH, CH, DH and BH, 16-bit forms, 8-bit shifts, address-size and segment prefixes, string ops, rotates, RCL, RCR, MUL and IDIV throw. A RIP-relative indirect call or jump is resolved by the import pass. Any other indirect call or jump stores the address and uses the RIP dispatch switch, which targets a recovered block or an import entry. An absolute relocation whose result lies in an executable file-backed PT_LOAD is a discovery root. Closes when: Remill is a submodule built from source.
- The [WebAssembly backend](../../../core/relinker/wasm/aot/src/Codegen.cpp) writes LLVM IR and compiles it with clang --target=wasm32 -O0 and wasm-ld instead of linking LLVM. Guest loads and stores go through a translator into the wasm32 window at offset 0. The window runs from the lowest PT_LOAD through the 64 KiB stack and must fit below the CPU-state page at 0xF0000. Holes in that span stay accessible and page protections are not enforced. Static data starts at 0x100000. Logical ALU clears AF, which Intel leaves undefined. The dispatch loop stops after one million steps. A halt leaves the resume flag clear; a Linux SIGILL frame sets it. Closes when: codegen links LLVM's WebAssembly backend in-process.
